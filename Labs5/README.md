# Лабораторная работа 5. Обработка строк

## Файлы

- `normalize.py` — нормализация текста
- `palindrome.py` — проверка на палиндром
- `replace.py` — замена `:` на `-` с подсчётом
- `variant.py` — индивидуальный вариант (номер задаётся константой `VARIANT` в начале файла)

## Принятые правила

- Слово — непустая часть, полученная через `split()`; в задании 1 знаки препинания остаются частью слова.
- Палиндром: игнорируются регистр и обычные пробелы `" "`, остальные символы (включая пунктуацию) сравниваются как есть.
- Вариант: по краям слова удаляются `.,!?;:`, слово переводится в нижний регистр, пустые результаты пропускаются, повторы сохраняются.

## Проверки

| Программа | Ввод | Ожидаемый результат |
|---|---|---|
| normalize | `  Один   два  ` | `Один два`, слов 2, длина 8 |
| normalize | пустая строка | длина 0, слов 0 |
| palindrome | `А роза упала на лапу Азора` | Палиндром |
| palindrome | `а    ` | Палиндром |
| palindrome | только пробелы | Нет текста |
| palindrome | `Python` | Не палиндром |
| palindrome | `А!` | Не палиндром |
| replace | `a::b:` | `a--b-`, замен 3 |
| replace | `abc` | `abc`, замен 0 |
| variant (1) | `Анна, армия! Я читаю.` | анна, армия; количество 2 |
| variant (2) | `Анна, армия! Я читаю.` | армия, я; количество 2 |
| variant (3) | `Анна, армия! Я читаю.` | армия, читаю; количество 2 |
| variant | пустой ввод | Нет совпадений, количество 0 |
| variant | `!!!` | Нет совпадений, количество 0 |

## Ответы на вопросы для защиты

- **Неизменяемость строк.** Методы вроде `lower()`, `strip()`, `replace()` не меняют исходную строку, а возвращают новую; результат нужно присвоить переменной или использовать сразу.
- **Слово и подстрока.** Слово — часть между пробельными символами (результат `split()`), подстрока — любой фрагмент строки. `"ра" in "рама"` — это подстрока, а не слово.
- **Правила пунктуации.** От них зависит результат: `А!` и `А` — разные строки для палиндрома, а `анна,` и `анна` — разные слова для варианта. Поэтому правила фиксируются до написания программы.
