## Формат `matrix.txt`

1. Первая строка: два положительных целых — число строк и столбцов.
2. Далее ровно указанное число строк, в каждой ровно указанное число целых.
3. Пустые и лишние строки — ошибка. Один перевод строки в конце допустим.

```
2 3
1 -2 3
4 0 -6
```

## Пример отчёта

```
Суммы строк: 2 -2
Суммы столбцов: 5 -2 -3
Результат варианта: 0
```

Результат варианта 0: в столбце с индексом 1 находятся `-2` и `0`, положительных нет.

## Вопросы для защиты

- **Ошибки формата и доступа.** Ошибка формата (`ValueError`) — содержимое файла не соответствует правилам. Ошибка доступа (`OSError`, `FileNotFoundError`) — файл нельзя открыть или прочитать: нет файла, нет прав. Первые исправляют в данных, вторые — в окружении.
- **Почему отчёт открывается для записи после проверки входа?** Режим `w` стирает содержимое. Если открыть отчёт до проверки и вход окажется неверным, прежний отчёт будет потерян. Поэтому весь отчёт сначала строится в памяти и записывается только при успехе.
- Порядок обработчиков: `UnicodeError` стоит раньше `ValueError`, так как является его подклассом.
