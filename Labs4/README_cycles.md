# Лабораторная работа 4. Циклы

## Что сделано

- range_numbers.py — вывод чисел от a до b включительно
- statistics.py — сумма, количество положительных и максимум
- positive_input.py — повторный ввод до положительного числа
- variant_cycles.py — подсчёт чётных чисел и их суммы

## Проверки

### range_numbers.py

Вход: `2 4`  
Ожидаемый результат:
```text
2
3
4
```

Вход: `4 2`  
Ожидаемый результат:
```text
4
3
2
```

### statistics.py

Вход:
```text
3
-5
-2
-8
```
Ожидаемый результат:
```text
Сумма: -15
Положительных: 0
Максимум: -2
```

### positive_input.py

Вход:
```text
0
-2
3
```
Ожидаемый результат:
```text
Квадрат: 9
Отклонённых попыток: 2
```

### variant_cycles.py

Вход:
```text
5
-2
0
3
10
20
```
Ожидаемый результат:
```text
Количество: 4
Сумма: 28
```

## Важные моменты

- `for` удобно, когда заранее известно число повторений.
- `while` удобен, когда условие выполнения зависит от значения.
- `break` завершает цикл, а `continue` пропускает текущую итерацию.
- Накопитель нужен для записи промежуточного результата.
