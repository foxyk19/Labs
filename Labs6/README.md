# Лабораторная работа 6. Списки и обработка наборов данных

## Файлы

- `statistics.py` — статистика по списку чисел
- `transform.py` — замена отрицательных чисел модулями в новом списке
- `positions.py` — все индексы максимального элемента
- `variant.py` — индивидуальный вариант (номер задаётся константой `VARIANT` в начале файла, сейчас `1`)

## Принятые правила

- Ввод: целые числа через пробел; пустая строка даёт пустой список.
- `statistics.py` и `positions.py` при пустом списке выводят `Нет данных` и не вызывают `min()`/`max()` и не делят на ноль.
- `transform.py` строит новый список через `append()`, исходный не изменяется.
- `variant.py` не изменяет выборку при сортировке: используется `sorted()`, а не `sort()`.

## Ответы на вопросы для защиты

- **Исходный список во втором задании сохранён.** Новый список `result` создаётся пустым и заполняется через `append()`; список `numbers` в цикле только читается. Программа выводит оба списка, и исходный остаётся без изменений.
- **`append()` и присваивание по индексу.** `items.append(value)` добавляет новый элемент в конец, длина списка растёт. `items[i] = value` заменяет уже существующий элемент, длина не меняется, а индекс за пределами списка вызывает ошибку.
- **`sorted()` и `sort()`.** `sorted(items)` возвращает новый отсортированный список и не трогает исходный. `items.sort()` меняет порядок в самом списке и возвращает `None`.
