# Лабораторная работа 2. Вычисления и проверка результата

## Цель

Переводить условие задачи в арифметическое выражение, выбирать тип данных, проверять ответ вручную. Необходимы ввод, вывод и преобразование типов из работы №1.

## 1. Прогнозы

До запуска программы считаем вручную:

- `2 + 3 * 4 = 14`
- `(2 + 3) * 4 = 20`
- `17 // 5 = 3`
- `17 % 5 = 2`
- `-7 // 2 = -4`

### Почему так?

- Умножение выполняется раньше сложения.
- `//` — это целочисленное деление: оно округляет вниз.
- `%` — это остаток от деления.
- Для отрицательных чисел `//` тоже округляет вниз, поэтому `-7 // 2 = -4`.

## 2. time_parts.py

### Вход

`3671`

### Ожидаемый результат

```text
1 ч 1 мин 11 с
```

### Фактический результат

```text
Введите количество секунд: 1 ч 1 мин 11 с
```

### Проверка

- `0` → `0 ч 0 мин 0 с`
- `59` → `0 ч 0 мин 59 с`
- `60` → `0 ч 1 мин 0 с`
- `3600` → `1 ч 0 мин 0 с`

## 3. purchase.py

### Вход

- цена: `45`
- количество: `3`
- сумма: `200`

### Ожидаемый результат

```text
Стоимость: 135
Сдача: 65
```

### Фактический результат

```text
Цена одной тетради: Количество тетрадей: Переданная сумма: Стоимость: 135
Сдача: 65
```

### Проверка

- `45, 3, 135` → стоимость `135`, сдача `0`
- `45, 0, 100` → стоимость `0`, сдача `100`

## 4. variant.py

### Вход

- общий объём: `21`
- вместимость: `10`

### Ожидаемый результат

```text
Полных единиц: 2
Остаток: 1
Минимальное число единиц: 3
```

### Фактический результат

```text
Общий объём: Вместимость одной единицы: Полных единиц: 2
Остаток: 1
Минимальное число единиц: 3
```

### Проверка

- `0, 10` → `0, 0, 0`
- `20, 10` → `2, 0, 2`
- `21, 10` → `2, 1, 3`

## 5. Дополнительно

В этой работе важно понимать:

- `/` даёт обычное дробное число;
- `//` даёт целую часть без дроби;
- `%` показывает остаток от деления;
- форматирование `:.2f` только выводит число с двумя знаками после запятой, но само число остаётся тем же.
