# Лабораторная работа 3. Условия и логические выражения

## Что сделано

- minimum.py — минимум из трёх чисел
- calculator.py — простой калькулятор
- point.py — проверка попадания точки в прямоугольник
- variant.py — выбор категории по значению от 0 до 100
- leap_year.py — проверка високосного года

## Проверки

### minimum.py

Вход: `2 10 3`  
Ожидаемый результат: `2`

Вход: `5 5 5`  
Ожидаемый результат: `5`

Вход: `-4 0 -2`  
Ожидаемый результат: `-4`

### calculator.py

Вход: `7 / 2`  
Ожидаемый результат: `3.50`

Вход: `5 / 0`  
Ожидаемый результат: `Деление на ноль запрещено`

Вход: `5 ? 2`  
Ожидаемый результат: `Неизвестная операция`

### point.py

Вход: `2 2`  
Ожидаемый результат: `Внутри или на границе`

Вход: `5 3`  
Ожидаемый результат: `Внутри или на границе`

Вход: `5.1 3`  
Ожидаемый результат: `Снаружи`

### variant.py

Вход: `-1`  
Ожидаемый результат: `Ошибка диапазона`

Вход: `0`  
Ожидаемый результат: `Низкий`

Вход: `20`  
Ожидаемый результат: `Средний`

Вход: `80`  
Ожидаемый результат: `Высокий`

Вход: `101`  
Ожидаемый результат: `Ошибка диапазона`

### leap_year.py

Вход: `1900`  
Ожидаемый результат: `Не високосный`

Вход: `2000`  
Ожидаемый результат: `Високосный`

Вход: `2024`  
Ожидаемый результат: `Високосный`

Вход: `2023`  
Ожидаемый результат: `Не високосный`

## Важные моменты

- `and` нужен, когда оба условия должны быть истинны.
- `or` нужен, когда достаточно хотя бы одного истинного условия.
- `if / elif / else` выполняет только первую подходящую ветку.
- При равных значениях программа выбирает первую подходящую проверку.
