# Лабораторная работа 7. Функции и автоматические проверки

## Файлы

- `functions.py` — функции `sum_digits`, `average`, `normalize_text` и `select_numbers` (вариант задаётся константой `VARIANT` в начале файла, сейчас `1`). Функции не вызывают `input()` и `print()`.
- `main.py` — демонстрация функций: ввод, вывод, точка входа `if __name__ == "__main__"`.
- `test_functions.py` — автоматические проверки на `assert`.

## Запуск

```
python main.py
python test_functions.py
```

## Принятые правила

- `sum_digits` работает с `abs(number)`, для нуля результат `0`.
- `average` возвращает `None` для пустого списка, исходный список не изменяет; `main.py` в этом случае выводит `Нет данных`.
- `normalize_text` приводит текст к нижнему регистру и оставляет по одному пробелу между словами.
- `select_numbers` возвращает новый список, порядок и повторы сохраняются.

## Проверки

| Функция | Вход | Ожидаемый результат |
|---|---|---|
| `sum_digits` | `0` | `0` |
| `sum_digits` | `507`, `-507` | `12` |
| `average` | `[]` | `None` |
| `average` | `[2, 4, 6]` | `4` |
| `normalize_text` | `"  ПРИВЕТ   Мир  "` | `"привет мир"` |
| `normalize_text` | `"   "` | `""` |
| `select_numbers` (вариант 1) | `[-5, 0, 2, 5]`, порог `2` | `[5]` |
| `select_numbers` (вариант 1) | `[1, 2, 3, 4]`, порог `2` | `[3, 4]` |
| `select_numbers` (вариант 1) | `[]`, порог `2` | `[]` |
| `select_numbers` (вариант 1) | `[-5, 0, 2]`, порог `2` | `[]` |
| `select_numbers` (вариант 1) | `[1, 2, 3]`, порог `2` | `[3]` (граница не включается) |
| `select_numbers` (вариант 1) | `[3, 5, 3, 1, 3]`, порог `2` | `[3, 5, 3, 3]` (повторы сохраняются) |

Тест также проверяет, что исходный список после вызова равен своей копии, сделанной заранее.

## Проверка, что тесты ловят ошибку

В `select_numbers` для варианта 1 условие `number > threshold` временно заменено на `number >= threshold`. Проверка `select_numbers([-5, 0, 2, 5], 2) == [5]` упала с `AssertionError` (функция вернула `[2, 5]`), то есть ошибка на границе обнаружена; проверка `select_numbers([1, 2, 3], 2) == [3]` поймала бы её тоже. После этого исправная версия возвращена, и `python test_functions.py` снова выводит `Базовые проверки пройдены`.

## Ответы на вопросы для защиты

- **Возврат и вывод.** `return` передаёт значение вызвавшему коду, его можно сохранить, сравнить в `assert` или передать дальше. `print()` только показывает текст человеку и ничего не возвращает: функция с одним `print()` вернёт `None`.
- **Локальная переменная и параметр.** Параметр — имя в определении функции (`numbers`, `threshold`), оно получает значение аргумента при вызове. Локальная переменная (`result`, `total`) создаётся внутри функции и существует только во время одного вызова.
- **Тест, который обнаруживает неправильное решение.** Если вместо `>` написать `>=`, проверка `select_numbers([1, 2, 3], 2) == [3]` получит `[2, 3]` и упадёт с `AssertionError`.
