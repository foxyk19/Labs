## 3. workload.py — нагрузка на неделю

### Входные данные

1. Первый предмет: `Математика`
2. Второй предмет: `Физика`
3. Занятия по matematikе: `3`
4. Занятия по физике: `4`
5. Продолжительность первого занятия: `45` минут
6. Продолжительность второго занятия: `30` минут
7. Доступное время на неделю: `12` часов

### Расчёт

- Математика: `3 × 45 = 135 минут`
- Физика: `4 × 30 = 120 минут`
- Общая нагрузка: `135 + 120 = 255 минут = 4.25 часа`
- Свободное время: `12 - 4.25 = 7.75 часа`
- Нагрузка за четыре недели: `255 × 4 / 60 = 17.00 часа`

### Ожидаемый и фактический результаты

| Проверка | Ожидаемый | Фактический |
|---|---:|---:|
| Математика | 135 минут | 135 минут |
| Физика | 120 минут | 120 минут |
| Общая нагрузка | 255 минут | 255 минут |
| Общая нагрузка в часах | 4.25 | 4.25 |
| Свободное время | 7.75 часа | 7.75 часа |
| Нагрузка за четыре недели | 17.00 часа | 17.00 часа |

Проверка: **успешно**.

## 6. variant.py — расчёт заказа

### Входные данные

1. Название заказа: `Магазин для животных`
2. Имя заказчика: `Иван Иванов`
3. Первая позиция: `Упаковки корма`
4. Количество первой позиции: `2`
5. Цена одной первой позиции: `150.00` рублей
6. Вторая позиция: `Игрушки`
7. Количество второй позиции: `3`
8. Цена одной второй позиции: `100.00` рублей
9. Стоимость доставки: `250.00` рублей
10. Внесённая сумма: `900.00` рублей
11. Скидка: `10%`

### Расчёт

- Стоимость упаковок корма: `2 × 150.00 = 300.00` рублей
- Стоимость игрушек: `3 × 100.00 = 300.00` рублей
- Стоимость товаров без доставки: `300.00 + 300.00 = 600.00` рублей
- Общая стоимость с доставкой: `600.00 + 250.00 = 850.00` рублей
- Общее количество единиц: `2 + 3 = 5`
- Сдача без скидки: `900.00 - 850.00 = 50.00` рублей
- Скидка: `600.00 × 10 / 100 = 60.00` рублей
- Новая стоимость товаров: `600.00 - 60.00 = 540.00` рублей
- Новая итоговая стоимость: `540.00 + 250.00 = 790.00` рублей
- Новая сдача: `900.00 - 790.00 = 110.00` рублей

### Ожидаемый и фактический результаты

| Проверка | Ожидаемый | Фактический |
|---|---:|---:|
| Первая позиция | 300.00 рублей | 300.00 рублей |
| Вторая позиция | 300.00 рублей | 300.00 рублей |
| Стоимость товаров | 600.00 рублей | 600.00 рублей |
| Общая стоимость с доставкой | 850.00 рублей | 850.00 рублей |
| Общее количество единиц | 5 | 5 |
| Сдача | 50.00 рублей | 50.00 рублей |
| Размер скидки | 60.00 рублей | 60.00 рублей |
| Новая итоговая стоимость | 790.00 рублей | 790.00 рублей |
| Новая сдача | 110.00 рублей | 110.00 рублей |
